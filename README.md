# MY ALIUCORD PLUGINS
to install these, you just download the zip file and put it in `/sdcard/Aliucord/plugins` ^_^

| Plugin                                                                                                                | Description                                                                                                                                                           |
|-----------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [NativeFriendNicknames](https://github.com/miaaaa0a/aliucord-plugins/raw/refs/heads/builds/NativeFriendNicknames.zip) | backports friend nicknames from the newer discord clients. uses the official api to retrieve/change them, so everything is automagically synced from all your devices |
| [ImageToClipboard](https://github.com/miaaaa0a/aliucord-plugins/raw/refs/heads/builds/ImageToClipboard.zip)           | adds an option to copy images to your system's clipboard. doesn't work on gifs                                                                                        |
